# Folio

A tiny native macOS portfolio tracker for crypto, cash and Milady / Remilio NFTs.

- Live prices, 7-day charts and NFT floors
- Transactions per holding (buy, sell, send, receive)
- Syncs through iCloud Drive
- Net Worth widget and menu bar item
- Updates itself via [Sparkle](https://sparkle-project.org)

**Install:** download the DMG from the [latest release](https://github.com/straypuma/deltaclone/releases/latest). The first time, macOS blocks it: go to System Settings ▸ Privacy & Security ▸ **Open Anyway**. Requires an Apple Silicon Mac on macOS 15+.

**Build:** `./build.sh` (`--install`, `--test`, `--release <version>`)
